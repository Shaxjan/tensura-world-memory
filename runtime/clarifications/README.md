# Clarifications

This directory stores durable clarifications that make accepted canon more precise without rewriting it.

A clarification is not a retcon and not an assistant-error repair.

Use `runtime/corrections/CORRECTION_TAXONOMY_v1.md` before adding a file here.

Examples:
- approximate value later reconciled to an exact value;
- role/location/item identity made more specific through causal information;
- ambiguous wording resolved without changing the underlying event.

# Global song scene display rule — latest retcon

Applies to ALL song performances in RP unless the user explicitly overrides it for a specific song or later replaces this rule.

Display structure for a song performance:
1. Verse 1: describe the performance and meaning; do NOT print the verse lyrics in full.
2. Verse 2: print the canonical verse 2 lyrics as text.
3. All remaining song sections/verses/choruses/outro after verse 2: describe the performance, progression, and NPC/world reactions; do NOT print their lyrics in full.

This rule supersedes earlier song-scene formatting corrections when they conflict.
Canonical lyrics remain stored unchanged in the song library; this rule governs only how performances are displayed in RP.

# Permanent song-scene formatting rule

User directive (T+160): whenever a song is performed in RP and its lyrics are shown, do NOT dump the entire text as one uninterrupted block.

Hard rule:
- Present lyrics according to the song's actual structure: verse -> chorus -> verse -> chorus, etc.
- Keep sections visually separated.
- Where appropriate, NPC/world reactions may appear between sections without interrupting the exact lyric text.
- Preserve the canonical wording of each lyric section exactly.
- This is a permanent rule for future RP song performances unless the user explicitly changes it.

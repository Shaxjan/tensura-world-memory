# Retcon: «Гвазимодо (Плач Горбуна)» — структура исполнения

На T+160 пользователь изменил способ показа песни в ролевой сцене.

Постоянная структура именно для исполнения этой песни:
1. Куплет 1 — только описание исполнения/содержания, без полного текста.
2. Куплет 2 — показать текст куплета.
3. Куплет 3 — только описание исполнения/содержания, без полного текста.
4. Куплет 4 — показать текст куплета.

Это реткон предыдущего способа показа песни в текущей сцене. Последняя пользовательская инструкция имеет приоритет.

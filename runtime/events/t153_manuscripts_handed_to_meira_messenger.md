# T+153 — Manuscripts handed to Meira's messenger

At approximately T+153 ~12:25 at 18 Old Garden Street / 18 Старая Садовая, Maestro Arlequino personally handed Meira's messenger four completed physical manuscripts for delivery to Meira / Eren for print preparation:

1. «Зов Ктулху»
2. «Маска Ктулху»
3. «Газель и Эмилия»
4. «Лейла и безумец»

This event establishes that these four manuscripts are no longer merely available at home: they have been transferred into Meira's delivery chain for the printing workflow.

Previously established intended print order among these four remains:
1. «Зов Ктулху»
2. «Маска Ктулху»
3. «Газель и Эмилия»
4. «Лейла и безумец»

The desired 50,000-copy run for «Зов Ктулху» remains an expressed target, not yet an accepted/confirmed production order pending capacity/cost calculations.

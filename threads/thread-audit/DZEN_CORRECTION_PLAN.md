## Процедура проверки очереди, когда будет отдельное разрешение

1. Экспортировать доступную фактическую очередь Дзена: ID записи, ссылку/редактор, текущую дату и время, текст, наличие фото/видео, состояние и фактические часы публикации. Не изменять запись во время чтения.
2. Сопоставить запись с публикацией Threads по последовательности нормализованных текстов и дополнительным идентификаторам/ссылкам, если они сохранились. Сходство одного первого абзаца **не гарантирует** полное соответствие.
3. Проверить все части цепочки в `parts` и собрать желаемый текст из `full_text_editorial`; сохранить отдельно исходный `full_text_original` для проверки на ошибочную редакторскую обрезку.
4. Проставить по каждой запланированной записи **одну основную категорию** и дополнительные флаги:
   - `COMPLETE`: вся значимая оригинальная история уже в Дзене.
   - `MISSING_PARTS`: есть содержательные части, которых нет в Дзене; составить точный список индексов и фрагментов.
   - `PROMO_OR_TECH`: текст Дзена содержит рекламную/служебную вставку, попавшую туда ошибочно.
   - `MEDIA_MISSING`: необходим оригинальный визуальный материал, которого нет в редакторе или проверенном архиве.
   - `EDITORIAL_REVIEW`: спорная авторская ремарка, вопросы аудитории, ненадёжный канон, фанфик или неоднозначное сопоставление.
5. Сформировать таблицу исправлений: `dzen_post_id`, `scheduled_at_msk`, `threads_post_id`, `threads_url`, `parts_count`, `missing_indexes`, `flags`, `original_dzen_text`, `proposed_full_text`, `media_requirements`, `edit_approved=false`.
6. Проверить по таблице дубли публикаций, изменение расписания, уже опубликованные материалы и случаи, где один Threads-пост случайно попал в несколько слотов. Показать предварительную сверку без записи изменений.
7. Только после **отдельного одобрения пользователя** исправлять подтверждённые недостатки, сохраняя даты/слоты, если не дано другое распоряжение. После записи вновь открыть каждую изменённую публикацию и сверить её содержимое.

## Правила редакторского текста

Оригинальные тексты не переписывать стилистически. Сохранять авторские абзацы, шутки, пол, терминологию и интонацию. В новых *редакторских* добавлениях — принятая терминология Росмэн, обычные кавычки и без длинного тире; исходный архив сохраняет оригинальную пунктуацию. Нельзя удалять кульминации и концовки ради сокращения. Не использовать рекламные ответы Telegram-бота как части статьи. Метрики постов относятся к прежнему снимку, а не к живой очереди Дзена.

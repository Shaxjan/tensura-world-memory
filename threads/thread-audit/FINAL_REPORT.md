Создан `threads/full-posts-verified.json` — единый индекс 414 авторских корневых публикаций с последовательными частями, оригинальными первыми текстами из Windsor.ai, двумя представлениями текста, метриками, форматами, ссылками, признаками медиа, классификацией и отметками качества. **Важно:** слово *verified* в имени файла означает структурно свёрстанный архив по проверенным браузером цепочкам, а не подтверждение идеальной дословности всех URL и не редакторское одобрение каждой истории. Выявленные ограничения маркируются на уровне каждой публикации.

## Главное исправление

В исходном `posts-by-format.json` хранилась только первая запись. В браузерных файлах у 80 публикаций первый текст оказался обрезан до последнего абзаца или фрагмента, включая примеры `DaHljTkiKIt`, `DdFEayhCfZ4`, `DcalTdlEaRI`. В итоговом архиве `parts[0].text` замещён полным `post_text` из исходного Windsor.ai, при этом браузерное несовпадение сохранено в `extraction_discrepancy`. Исходные 53 файла не переписывались.

Единственный исходный пост без `post_text` — `18077890988299407` (`DaX_Gh1CGYO`), тип IMAGE. При точечном открытии его страницы не обнаружено отдельного исходного текста, а строка «Ответьте mirpottera…» являлась элементом интерфейса. Не внесена в авторский текст.

`full_text_original` объединяет доступный текст всех пронумерованных частей. `full_text_editorial` сохраняет главную историю, **включая короткие авторские дополнения и вопросы**, и исключает только автоматически определённую рекламу и служебные атрибуции; спорные дополнения помечены для редактора. Удаление или изменение исходных реплик не выполнялось.

## Нерешённые ограничения и задачи точечной сверки

1. **201 сокращённая рекламная ссылка**, встречающаяся в браузерном извлечении, например `t.me/mir_p…`. Их оригинальный полный вид нельзя восстановить из показанного текста достоверно. В архиве сохранён извлечённый вариант; указаны `flags.truncated_url`, `completeness.original_text_status=display_truncated_urls` и ссылка на конкретную часть. Эти сообщения **не включаются автоматически в текст для Дзена**. Для совершенно дословного архива нужно прицельно раскрыть ссылки на страницах либо получить полные тексты из API.
2. **109 публикаций с дополнительными материалами** отмечены `editorial_decision_for_supplement` (107 дополнений и 6 вопросов распределены между ними). Короткая концовка может быть важной авторской мыслью: по умолчанию она сохранена в `full_text_editorial`, а не потеряна.
3. **73 визуальных формата** требуют отдельной сверки собственно изображения, видео или карусели перед использованием в Дзене; GitHub не является гарантированным архивом их медиафайлов.
4. **Канон/фанфик:** цепочка о Добби (`DeYUypOEwbE`, 14 частей) представляет авторскую альтернативную историю; её нельзя представлять как канон. Проверка остальных сюжетных фактов по книгам не была частью машинной проверки структуры.
5. **Обратное чтение большого файла:** GitHub подтвердил создание `full-posts-verified.json` коммитом `10d79a1d5db8f7b422adf3aa9f3605805a43743a`; при попытке загрузить всё содержимое через подключённое `fetch_file` файл свыше 1 МБ вернул пустой `content`, хотя blob SHA и URL доступны. Поэтому полный побайтовый round-trip **не подтверждён**. Четыре исходных merge-stage файла содержат исходные 414 записей и позволяют повторно построить финальный файл; в будущем проверить через git clone/raw download или Git API для крупных blobs.

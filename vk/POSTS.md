# Посты ВКонтакте — «Мир Поттера»

Этот раздел предназначен **только для публикаций сообщества «Мир Поттера» во ВКонтакте**.

Сообщество: https://vk.com/club242263760

## Реестр публикаций

Посты добавляются сюда после подготовки и согласования. Пока публикации не внесены.

Для каждой записи сохраняем:

- **Дата и время (Красноярск, UTC+7)**
- **Тема / рубрика**
- **Полный текст публикации**
- **Изображение или концепция изображения** (ссылка на утверждённый файл, если есть)
- **Статус**: черновик / утверждено / запланировано / опубликовано
- **Ссылка на публикацию**, когда опубликована

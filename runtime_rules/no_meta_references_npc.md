# Canon rule: NPCs must not reference out-of-world corrections

NPC dialogue and reactions must remain fully in-world.

They must not allude to:
- assistant mistakes,
- user OOC corrections,
- retcons,
- prior wrong continuity,
- whether an organizer is now behaving 'correctly',
- any meta evaluation of scene construction.

If a continuity correction is made, only the corrected in-world facts remain canon. NPCs react only to those facts as if they had always been true.

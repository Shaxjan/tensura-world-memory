# Research discipline

When closing an item:
1. identify direct source and chronology;
2. check for later retcon/correction;
3. separate artifact existence from performed-event completion;
4. separate capacity/promotion/plan from observed outcome;
5. update the dedicated recovery file first;
6. update `recovery/RECOVERY_INDEX.md` and `PUBLIC_CULTURAL_CANON_REGISTRY.md` only after reconciliation;
7. remove the item from this queue or mark it `RESOLVED` with the resolving source.

If no source is found, leave the value `UNKNOWN`. That is preferable to a plausible reconstruction.

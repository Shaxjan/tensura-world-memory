# GAMEPLAY INPUT & SONG REACTION CADENCE RULE v1

Status: HARD RULE

Scope: all active Tensura World gameplay chats, with special emphasis on live performances and songs.

## 1. Player input syntax

The following syntax is authoritative and must be interpreted exactly:

- `( ... )` = OOC instruction addressed to the assistant. It is NOT speech by Arlequino, NOT an action by Arlequino, and NOT an in-world event unless the instruction explicitly orders a retcon/canon change.
- Plain text without surrounding parentheses and without a leading `-` = Arlequino's action.
- A line beginning with `-` followed by text = words spoken by Arlequino in-world.

Never convert an OOC parenthetical instruction into dialogue or action. Never narrate plain player action text as if it were only a suggestion. Never treat a leading-dash spoken line as narration.

## 2. Song text display rule

When the player says they sing a named song and explicitly asks for the whole song / full text / `всю песню` / `текст`, the gameplay response must show the full authoritative stored song text directly in the response, in canonical order, rather than replacing it with a summary such as `Arlequino sings the whole song`.

If a canonical song archive exists in the repository, use that exact stored text. Do not reconstruct from memory and do not silently normalize wording.

## 3. Reaction cadence during full-song playback

For future full-song performance scenes, world/NPC/audience reactions should normally be inserted after every 4 lines of sung text.

Default structure:

1. show 4 lines of the canonical song text;
2. show a concise causal reaction beat to those specific lines;
3. continue with the next 4 lines;
4. repeat until the song ends.

The final block may contain fewer than 4 lines if the song length is not divisible by four.

This cadence is a presentation rule, not permission to fabricate reactions. Reactions must still obey causal perception, NPC autonomy, crowd heterogeneity, cultural context, hearing limits, scene physics and player-agency rules.

## 4. Reaction density

Reaction beats should be concise enough that the song remains the dominant content of the turn. Do not bury the lyrics under long commentary. A reaction beat may mention multiple relevant observers or crowd sectors together when causally appropriate.

No requirement exists for every NPC to react after every four lines. The cadence means the simulation checks and, when appropriate, displays reactions at those four-line intervals; silence, distraction or no visible reaction are valid outcomes.

## 5. Player agency

Displaying full song text because the player explicitly authorized singing the full song authorizes only that performance from beginning to end. It does not authorize any post-song bow, speech, gesture, movement, emotion, next song, romantic action, concert transition or other voluntary act by Arlequino.

This rule supplements `LIVE_PERFORMANCE_REALISM_AND_PLAYER_AGENCY_RULE_v1.md` and does not weaken any existing autonomy, causality or knowledge-provenance rule.

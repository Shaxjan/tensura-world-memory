# SONG RESPONSE CHUNKING RULE v1

Status: HARD RULE

Scope: full-song performance turns in active gameplay.

1. If a song is too long to display comfortably in one assistant response, split the performance into exactly 3 sequential assistant responses.
2. Preserve the exact performed text and order. Do not repeat or skip lines between parts.
3. Within each part, present 4 song lines, then a short in-world reaction, then the next 4 lines.
4. Reactions should be concise and causal, normally 1–3 sentences, and must not overwhelm the song text.
5. The three assistant responses together represent one continuous performance. Do not treat the boundaries between responses as in-world pauses unless the player explicitly creates a pause.
6. Do not advance to another song, speech, bow, gesture, or voluntary Arlequino action after the final part unless the player authorizes it.
7. Existing input syntax remains authoritative: `( ... )` is OOC to assistant; plain text is Arlequino action; text beginning with `-` is Arlequino speech.

# songs — канонические тексты песен

ЭТА ПАПКА — ПЕРВОЕ И ОСНОВНОЕ МЕСТО ПОИСКА ЛЮБОЙ ПЕСНИ С ТЕКСТОМ В RP.

Правило введено пользователем на T+160: больше не искать тексты песен по всему репозиторию.

## Правила хранения

- Любая новая песня, для которой пользователь дал полный или канонизированный текст, должна быть сохранена/обновлена здесь в том же рабочем цикле.
- Одна песня = один файл, когда это технически возможно.
- Если точный текст приходится хранить частями, использовать отдельную подпапку с README/index и строгим порядком частей.
- Сохранять текст дословно. Не исправлять орфографию, пунктуацию, регистр, повторы, растянутые окончания и авторские формулировки без прямой команды пользователя.
- Последняя явная правка/реткон пользователя имеет приоритет над более ранними версиями.
- Никогда не восстанавливать пропущенные строки по памяти, вебу, исходной песне или догадке.
- Старые `song_archive/`, `runtime/` и другие файлы остаются историческими источниками и не удаляются, но после этого правила НЕ являются первым местом поиска текста.
- Неполные/утраченные тексты собраны в `_partial/`; их нельзя выдавать за полный канон.

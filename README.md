# Мир Поттера — журнал контента

Этот репозиторий используется как постоянная база публикаций Threads-проекта **«Мир Поттера»**.

## Зачем он нужен

Перед предложением новой темы проверять журнал и понимать:
- публиковалась ли уже эта тема;
- под каким углом она выходила;
- в каком формате;
- какие были метрики;
- можно ли сознательно вернуться к теме с другим углом.

**Повтор персонажа или темы не запрещён.** Запрещено выдавать уже использованный угол за новую идею.

## Файлы

- `posts.json` — основная структурированная база.
- `POSTS.md` — короткая человеческая хронология.

## Поля записи

`date`, `slot`, `status`, `format`, `topic`, `angle`, `final_text`, `visual`, `metrics`, `notes`.

Статусы: `planned`, `scheduled`, `published`.

## Правило обновления

После утверждения/планирования/публикации поста добавлять или обновлять запись. После получения аналитики дописывать метрики.

# Tensura Simulation Engine v0.7 — Source-grounded Cutover Baselines

v0.7 does not add combat tricks or new world breadth. It resolves migration debt without converting missing history into invented facts.

## What becomes authoritative

The rehearsal imports repository sources with provenance and SHA-256:

- `memory/money.json`
- `memory/places.json`
- `memory/relationships.json`
- `memory/actions.json`
- the NPC autonomy rules
- the economy model rules

Every imported baseline is tagged with source, authority, status and (where applicable) the SAVE version it is exact as of.

## Positions

An exact NPC street/building is no longer required just to represent an NPC. Positions have precision: named place, region only, or unknown. Vern's current trip progress remains unknown. Borga can be known to belong to the current Eurazania-capital context without inventing his exact yard or room at the instant Arlequino starts looking for him.

## Relationships

Saved relationship history is imported as qualitative evidence. v0.7 deliberately does not assign retrospective affinity/trust/respect numbers. Numeric mechanics are a separate `NON_CANON_MECHANICAL` calibration layer.

## Money

The current personal purse remains the exact LIVE value. Historical separate-fund balances are imported with their exact-as-of version. Every later delta is scanned for account-related mentions. A later mention prevents v0.7 from claiming that the older balance is still current; it becomes a reconciliation item instead of a guessed debit/credit.

## Autonomous baseline

Active NPC tasks, mail, festival/tournament commitments and autonomy hard rules define a prospective autonomous epoch at cutover. The engine does not backfill unseen off-screen events merely to create a complete-looking history.

## Markets and routes

Laboratory v0.3 markets, commodity prices and route durations remain non-authoritative and are purged from the migration runtime. The economy model is imported as a rule system. Market/route creation is prospective only: future values may be established by an observed transaction/trip or by a separately calibrated deterministic generator. They are never presented as historical SAVE values.

## Malformed historical deltas

Malformed old deltas stay byte-for-byte in `campaign_archives`. v0.7 reclassifies this from a current-state migration blocker to accepted historical semantic degradation when the current pointed delta is valid and the raw archive is complete. It does not repair old JSON by guess.

## Cutover gate

v0.7 still keeps gameplay commands locked. Remaining calibration/reconciliation debt is explicit, typically: player power calibration; player skill calibration; relationship mechanics calibration; market calibration; route calibration; and any separate fund whose last exact balance has later unresolved mentions.

`live_cutover_ready` therefore remains false by design. The next version should calibrate only these prospective mechanics, then run a shadow campaign turn against the current LIVE state before any real switch.

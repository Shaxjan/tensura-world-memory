# Simulation Engine v1.0.10 — Causal NPC Response Resolver

v1.0.10 adds the first bounded authoritative response policy for a persistent named character.

## Scope

The first calibration is deliberately narrow: **Borga + simple direct greeting**.

A new greeting can resolve only when all of the following are true:
- Borga is directly visible in the player's current local scene;
- the player explicitly addresses Borga through safe named-target grounding;
- the accepted turn contains a `speech_or_request` component;
- v1.0.7 has already recorded the causal encounter memory for this same turn;
- Borga's current persistent Character Plan grounds his exact presence at the same place in a `role_duty` block;
- the utterance is only a greeting, not a question, request, proposal or other contentful social action.

The result is a minimal reciprocal greeting with zero full clock minutes. The canonical surface mirrors one recognized greeting phrase such as `Доброе утро.`.

## What this does not infer

The response does **not** create or infer:
- personality traits;
- tone or emotion;
- approval/disapproval;
- friendship, trust, attraction or other relationship state;
- consent;
- willingness to continue the conversation;
- hidden reasons or hidden Character Plan details.

Anything beyond the calibrated greeting remains unresolved for later social-response layers.

## Causal storage

The hidden prospective response policy lives inside Borga's Character Core.

A response that actually occurs is stored separately as a player-observed fact:
`v110:player_observed_response:borga:<turn_key>`.

Only the observable response enters player knowledge. Hidden plan/scheduler reasoning never enters the observable response fact.

## Continuity

Activation is zero-time and prospective only. It must not retroactively resolve `chat-20260824-greet-borga-r000013` or any earlier greeting.

The first authoritative response must come from a **new player turn after activation**.

## Rehearsal gate

The LIVE rehearsal starts from the current v1.0.9 head, proves the old greeting remains unresolved, activates v1.0.10, then submits a new shadow greeting and requires:
- one `return_greeting` response from Borga;
- exact observable surface `Доброе утро.`;
- 0 clock minutes;
- exactly one new causal encounter memory for the new address;
- no relationship/personality/emotion delta;
- no remaining pending resolution;
- direct player knowledge of the observed response;
- deterministic replay;
- read-only session-state construction.

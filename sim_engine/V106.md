# Tensura World Memory — v1.0.6 Intent Grounding Repair

## Why this version exists

Live v1.0.5 exposed a real parser defect on player turn `r000006`:

`Илу в малый тренировочный лагерь.`

No movement occurred, but the generic scene fallback created a pending target for `Рена`, even though Rena was not mentioned.

Root causes:

1. named-NPC matching used raw substring stems; the stem `рен` from `Рена` matched inside `тренировочный`;
2. known-local travel required a narrow movement token and exact place aliases, so the typo `Илу` plus the user's lexical variant `лагерь` missed the finite local-travel resolver.

## v1.0.6 rules

### Safe named-target grounding

Named actors are matched by normalized tokens and explicit inflection forms, not arbitrary substrings inside unrelated words.

Examples:
- `к Рене` may ground Rena;
- `Рену` may ground Rena;
- `тренировочный` must never ground Rena.

Generic fallback may remain pending when an action truly lacks mechanics, but it may not attach an unmentioned named NPC merely because a character-name stem occurs inside another word.

### Known-local typo repair

The existing v1.0.1 finite local-travel resolver remains authoritative. v1.0.6 only widens safe recognition:
- ordinary canonical aliases keep working;
- the observed live typo `Илу` is accepted as a movement token;
- a lexical variant such as `малый тренировочный лагерь` resolves to the small training yard only when the player already has causal knowledge pointing to `eurazania_small_training_yard`.

The lexical repair does not create a new place or retroactively rename the canonical place.

### Repair of r000006

The existing `j000006` is immutable and remains in history.

Activation creates a new append-only system event that:
- cancels only the false pending targeting Rena;
- marks the malformed scene action as superseded by parser repair;
- records that the bad turn had no world effect;
- advances zero game minutes;
- changes no money or region;
- does not execute movement on the player's behalf.

The player's next equivalent movement command is then parsed under v1.0.6 and can resolve normally as finite local travel.

## Guardrails

- Never rewrite `j000006`.
- Never infer Rena involvement from `тренировочный` or another unrelated token.
- Never use fuzzy place wording alone to invent a destination; the small-yard lexical repair requires existing player knowledge of that lead.
- Activation is technical recovery, not a player choice.
- Existing Character Core and Character Autonomy semantics remain unchanged.
- UNKNOWN stays UNKNOWN.

# Simulation Engine v1.0.2 — Session Fast Path + HUD

v1.0.2 is a live-stability release. It does not add new world mechanics.

## Goals

- Stop full checkpoint/history reconstruction on every ordinary GM response.
- Maintain a compact `runtime/session_state.json` generated only from authoritative engine state.
- Require every game reply to show time, current location, personal money on hand, and personal money elsewhere.
- Keep family/project/promo/earmarked/payable funds out of personal-money totals.
- Keep entrusted balances UNKNOWN when no causal settlement exists.
- Hide hashes/journal/migration diagnostics during normal play.

## Activation

v1.0.2 compacts the current authoritative head into a new immutable checkpoint and sets `journal_base_seq = journal_seq`. This is required because v1.0.2 changes GM packet/read-model semantics; old journal events remain immutable history and are not replayed under changed presentation semantics.

The activation itself does not advance game time and does not create a gameplay event.

## Current HUD expectation at activation

- Time: `T+131 ~07:54`
- Location: `большой тренировочный двор Борги`
- On person: `26g 05s 92c`
- Personal money elsewhere: Vern instrument float current remainder `UNKNOWN`, known entrusted principal `50s`.

Project/family/promo funds are explicitly excluded from this personal HUD.

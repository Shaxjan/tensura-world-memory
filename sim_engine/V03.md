# Tensura Simulation Engine v0.3 — Regional World Layer

v0.3 is a laboratory layer for autonomous factions, delayed information, regional markets, level-of-detail simulation, and relevance-filtered LLM context. It does **not** replace the live Arlequino campaign.

## Acceptance goals

1. Factions act without player input.
2. Information cannot teleport between regions; it travels hop-by-hop with route delay.
3. Large populations are simulated as cohorts/macros, not one decision per resident.
4. Local prices react to supply/demand, stock never goes negative, and the seeded economy does not systemically collapse during the probe.
5. The narrator receives a small local context rather than the database or hidden remote truth.

## Implemented

### Autonomous factions
Factions own treasury, goals and an independent action clock.

- guard factions can spend resources on security after credible threat information actually reaches their region;
- merchant factions inspect regional markets and dispatch real stock-bearing caravans;
- faction actions continue while the player does nothing.

### Delayed information
Facts begin only in their origin region.

Information moves as packets over real routes. Courier and rumor modes have different delays/confidence loss. A region can relay a newly received belief onward, but the information does not appear globally at creation time.

Regional belief and player knowledge are separate tables.

### Regional economy
Each region/commodity pair stores integer stock, target stock, demand, daily production, daily consumption and integer price.

Prices move gradually from scarcity rather than being invented by the LLM. Player market purchases are atomic. Merchant caravans remove stock from their origin immediately and add it to their destination only after travel completes.

### Level of detail
The player's region is `full`, directly connected regions are `active`, and remote regions are `macro`.

The current lab contains 164,000 simulated residents but represents them as population cohorts. Routine pressure is updated by region/group rather than by running 164,000 autonomous LLM agents.

### LLM context boundary
`build_context()` returns only current player state, current local region, local markets, local factions, facts explicitly known to the player, and a handful of significant local events. Remote secrets and world truth are not included merely because they exist in SQLite.

## Validation

Run:

```bash
cd sim_engine
python -m unittest -v test_v03.py
python v03_probe.py --days 30
```

Local result: **13/13 tests pass**.

The tests cover no player autopilot, autonomous faction actions, delayed multi-hop information, scarcity-driven prices, atomic purchases, physical stock-bearing trade caravans, player-relative LOD, macro simulation instead of per-person event spam, small/local LLM context, no global-truth leak into player context, security response only after threat information arrives, deterministic seeded replay, and 30-day essential-food market non-collapse.

## 30-day no-player probe

The first long probe exposed a real flaw: the seeded grain economy had structural underproduction, and several regional markets eventually reached zero stock. That result was rejected rather than accepted.

The seed balance and merchant routing were then changed:

- total grain production now exceeds structural consumption;
- merchant factions can route to any reachable region rather than only direct neighbors;
- caravan quantities respond to actual shortage and available surplus.

After the fix, a fresh 30-day deterministic probe produced:

- population represented: **164,000**;
- player location/cash changed autonomously: **no**;
- macro ticks: **120**;
- faction actions: **313**;
- information packets delivered: **5**;
- completed trade caravans: **168**;
- total engine events: **488**;
- generated LLM context: about **1.7k characters**;
- grain stock after 30 days: Blumund **1,380** at 18c; Dwargon **9,620** at 14c; Eurazania **1,450** at 18c; Jura edge **2,330** at 14c.

These are diagnostic numbers, not target balancing.

## What v0.3 still does not solve

The world is more autonomous, but it is not yet ready for the live campaign. Missing layers include combat/skills/checks/injury/death, robust named-NPC schedules and appointments, law/crime/authority/reputation, relationship memory, memory salience and forgetting, deeper faction diplomacy, weather and route hazards, calendar commitments, canon-event injection, validated player-action commands, and migration tooling for the real Arlequino history.

## Gate for v0.4

Do not migrate the live campaign until v0.4 proves that player actions can be translated into validated engine commands without arbitrary LLM state mutation; checks/combat/injury are deterministic and auditable; NPC appointments survive long time jumps; law/reputation create consequences independently; important memories persist while trivial events decay; and canon/world events can enter without giving every NPC impossible knowledge.

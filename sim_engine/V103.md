# Simulation Engine v1.0.3 — Living Scene Runtime

v1.0.3 fixes the first post-cutover world-presence failure: `UNKNOWN named NPC location` must not mean `empty place`.

## What changes

- Known local places now support a persistent, deterministic prospective ambient scene.
- Ambient people are anonymous engine state: roles, small groups and current activity appropriate to the place/time.
- They persist long enough for follow-up interaction instead of disappearing on the next message.
- Ambient generation never retroactively creates named canon or private knowledge.
- Named NPC positions remain separate from ambient population.
- Borga receives the first prospective named routine calibration because the current live action is already searching for him and his work ties to the three training sites are source-grounded.
- A local Borga search is finite: 6 game minutes, autonomy runs during that time, and the result is one of direct find, causal local lead/testimony, or not found with no exact lead.
- A lead is evidence, not omniscience. It does not guarantee Borga remains at the stated place until the player arrives.
- Normal arrival/observation packets include ambient activity so the GM can narrate a populated place naturally.
- v1.0.2 HUD requirements remain mandatory.

## Authority model

Ambient people and current named-routine slots are `NON_CANON_MECHANICAL_PROSPECTIVE`. They govern future simulation from the moment the engine creates them. They are not claims about the unseen historical past.

The engine stores v1.0.3 prospective local state in existing `facts` and `events` tables. No new SQLite schema is added; therefore the v1.0.2 authoritative head can be compacted without changing its hash.

Named NPC information remains causal: `hidden prospective schedule -> direct observation/testimony -> player knowledge`.

## Current LIVE migration

At activation, the current v1.0.2 head is compacted unchanged into `runtime/checkpoints/v103_base_jNNNNNN.json`.

If the existing Borga search is still pending, v1.0.3 creates one system journal event that resumes **that already-authorized action**. It is not a new player choice. The search consumes exactly 6 game minutes, runs world autonomy, resolves the old pending, materializes the current yard's ambient scene, and writes the result to the session fast-path.

Old journal events remain immutable.

## Guardrails

- Never turn anonymous ambient entities into established named canon without an explicit materialization/interaction transition.
- Never place an uncalibrated named NPC just because a location would be convenient.
- Never upgrade testimony to certainty.
- Never alter player cash merely because a scene is populated.
- Never choose Arlequino dialogue, feelings, decisions or significant actions.
- `UNKNOWN` remains `UNKNOWN` when no causal observation exists.

# Simulation Engine v1.0.7 — Causal Encounter Memory

Статус: candidate до успешных tests/rehearsal/activation.

## Цель

Добавить первое долговременное личное воспоминание persistent named character без выдумывания эмоций, отношений, ответа или скрытого знания.

Первая калибровка: Борга.

## Главный causal rule

`PLAYER OBSERVES BORGA` не означает `BORGA OBSERVES PLAYER`.

Память Борги создаётся только если одновременно выполнены условия:
1. Борга уже causally visible в текущей локальной сцене;
2. новый ход Арлекино принят движком;
3. текст явно адресует/упоминает Боргу через safe named-token grounding v1.0.6;
4. ход содержит наблюдаемое обращение/взаимодействие (`speech_or_request`, `interaction_attempt`, `handoff_offer`, либо явно адресованное performance).

Простой поиск, обнаружение или взгляд игрока на Боргу память Борги не создаёт.

## Storage

Старый `memories` table v0.4 имеет FK на `actors`, а current production не материализует Боргу как generic actor. Создавать fake actor с `cash=0`/invented stats запрещено.

Поэтому v1.0.7 использует существующий authoritative `facts` store:
- `v107:character_memory:borga:<turn_key>` — immutable-by-key causal memory fact;
- `Character Core.memories` — ссылки на эти memory facts.

Это сохраняет единую authoritative fact/state chain и не создаёт ложные generic actor attributes.

## Что хранит encounter memory

- owner/counterpart;
- world minute;
- region/place;
- source turn;
- verbatim observable player text;
- observable component kinds;
- causal basis;
- confidence;
- explicit negative assertions.

Не хранит как факт:
- эмоцию Борги;
- approval/disapproval;
- изменение отношений;
- ответ Борги;
- consent/acceptance;
- истинность сказанного игроком.

## Character Core

Activation только подключает `memory_model` к существующему Core. Уже существующий `memories` list сохраняется без изменений.

Никакая предыдущая встреча/поиск не импортируется ретроактивно.

## Replay / activation

v1.0.6 head сначала compact-ится без изменения в новый v1.0.7 base checkpoint.

`causal_encounter_memory_activation`:
- append-only;
- 0 игровых минут;
- не является выбором игрока;
- не меняет деньги/регион/место;
- не создаёт память из r000009;
- не materializes Borga в generic `actors`;
- сохраняет последний игровой turn.

## Regression gate

Rehearsal стартует с текущего LIVE после r000009, где Арлекино напрямую видит Боргу:
1. activation не создаёт memory;
2. shadow player turn `Говорю: «Борга, доброе утро.»` создаёт одну causal memory;
3. relationships не меняются;
4. generic actor Borga не создаётся;
5. replay activation + interaction даёт идентичный state hash.

# Books / literary texts

This folder stores full literary texts and Tensura-world adaptations used in the RP.

## Persistence rule
- One work = one dedicated Markdown file (or one subfolder if the work becomes large/serialized).
- Save the actual narrative text here, not only a runtime summary.
- `runtime/significant_events/` keeps scene facts, who heard what, retcons, and knowledge boundaries; it is not the primary storage for the book text itself.
- When Arlequino narrates or writes a new passage in play, append/persist that passage to the corresponding book file at a significance boundary rather than relying only on chat memory.
- Preserve the established version of the wording. Later explicit corrections/retcons supersede earlier text and must be applied to the book file.
- Adapted works must remain internally native to the Tensura setting: no modern-Earth technology, institutions, infrastructure, or geography unless explicitly established in-world.

## Current adapted works
- `tensura_adaptations/zov_ktulhu.md` — «Зов Ктулху», Tensura adaptation.
- `tensura_adaptations/maska_ktulhu.md` — «Маска Ктулху», Tensura adaptation.

Do not fabricate missing passages. If an earlier full passage is not recoverable, mark that gap and recover it from prior canon before filling it.
